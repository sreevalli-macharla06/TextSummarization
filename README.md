# AI Text Summarization Tool

## Project Description
This project is an AI-based Text Summarization Tool developed using Python and Hugging Face Transformers.

The tool takes a long paragraph as input and generates a short and meaningful summary automatically using Natural Language Processing (NLP).

---

## Technologies Used
- Python
- Transformers
- Torch
- NLP (Natural Language Processing)

---

## Features
- Accepts long text input
- Generates concise summaries
- Uses pretrained AI model
- Easy to use and beginner friendly

---

## Files in Project
- summarization.ipynb
- requirements.txt
- README.md
